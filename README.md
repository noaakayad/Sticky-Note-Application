# Sticky Note Application

This repository contains a small React and TypeScript sticky-note application.

The project was built to practice React fundamentals, forms, event handling, component state, context and typed frontend development.

## Features

- Create and manage sticky notes.
- React component-based interface.
- TypeScript types for note data.
- Theme context setup.
- Form and event-handling practice.

## Technologies

- React
- TypeScript
- CSS

## Repository Structure

```text
App.tsx
App.css
ThemeContext.ts
hooksExercise.tsx
types.ts
constants.ts
index.tsx
index.css
```

## Usage

This repository contains the source files of the app. In a standard React setup, place these files in the `src/` folder and run:

```bash
npm install
npm start
```
